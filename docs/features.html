เข้าสู่ระบบ

ใครเข้าที่เข้าสู่ระบบอย่างไร

ลูกค้า — จองและจ่ายเงินเองทางมือถือ

1สมัคร / เข้าสู่ระบบด้วยเบอร์โทร
2เลือกกีฬา วันที่ สนาม และชั่วโมง (เลือกได้หลายชั่วโมง)
3ดูราคา (ช่วงปกติ/Peak + ส่วนลดตามระดับสมาชิก)
4สแกน QR พร้อมเพย์ ยอดขึ้นอัตโนมัติ และอัปโหลดสลิป
5พนักงานตรวจสลิป → การจองยืนยัน + ได้แต้ม

สนามและเวลา

  • แบดมินตัน บาสเกตบอล พิกเคิลบอล ห้องประชุม
  • บาสฯ สนาม A, B, C จองได้ทั้งสนามเต็มหรือครึ่งสนาม
  • จองล่วงหน้าได้ตามที่ร้านตั้ง (เช่น 30 วัน) ในเวลาเปิด-ปิด
  • ช่องที่ถูกจองหรือปิดปรับปรุงจะเลือกไม่ได้

การจ่ายเงิน

  • มีเวลาจ่าย 30 นาที เกินแล้วการจองถูกยกเลิกอัตโนมัติ
  • หน้าจ่ายเงินแสดงชื่อบัญชีผู้รับ ให้ตรวจก่อนโอน
  • สลิปถูกปฏิเสธ → อัปโหลดใหม่ได้

แต้มและของรางวัล

  • ได้ 1 แต้มต่อ 100 บาท (จองสนามและซื้อของที่เคาน์เตอร์)
  • แลกของรางวัล เช่น ชั่วโมงฟรีช่วง Off-peak → ได้รหัสคูปองไปใช้ที่เคาน์เตอร์
  • ดูการจองและคูปองของตัวเองได้ในแอป

พนักงานเคาน์เตอร์

ต้องเปิดกะก่อนรับเงินสด — ถ้ายังไม่เปิดกะ ระบบจะไม่ให้บันทึกเงินสด และพาไปหน้าเปิดกะ

จอง Walk-in

  • เลือกสนาม วันที่ เวลา แล้วรับเงินสด / พร้อมเพย์ / คูปอง
  • ช่องเบอร์มี รายชื่อสมาชิกให้เลือก พิมพ์เบอร์หรือชื่อเพื่อค้นหา
  • เลือกสมาชิกแล้ว ชื่อมาจากระบบ แก้ไม่ได้ และสมาชิกได้แต้ม

ตรวจสลิปโอน

  • คิวสลิปที่ลูกค้าอัปโหลด → อนุมัติ หรือ ปฏิเสธพร้อมเหตุผล
  • สลิปเดียวกันใช้ซ้ำกับการจองอื่นไม่ได้

ขาย F&B / อุปกรณ์

  • กดสินค้าใส่ตะกร้า เลือกเงินสดหรือพร้อมเพย์
  • ตัดสต๊อกอัตโนมัติ ของหมดขายไม่ได้
  • ใส่เบอร์สมาชิกเพื่อสะสมแต้ม

เช่าอุปกรณ์

  • ไม้แบด รองเท้า (เลือกเบอร์และชาย/หญิง)
  • รายการที่ยังไม่คืน → กด "คืน" เมื่อลูกค้านำมาคืน

รับของรางวัล

  • พิมพ์รหัสคูปองของลูกค้า → ตรวจสอบและมอบของ / ใช้ชั่วโมงฟรี

ใบเสร็จและสรุปยอด

  • ใบเสร็จแสดงชื่อร้าน ผู้รับเงิน และเวลาที่รับเงิน (มี VAT ถ้าร้านจด VAT)
  • ยอดลิ้นชักวันนี้ (ดูอย่างเดียว)
  • ปิดกะแบบนับเงินก่อน ไม่เห็นยอดที่ควรมี (blind count) ถ้าไม่ตรงต้องใส่หมายเหตุ
  • บันทึกลูกค้าไม่มาเล่น (No-show)

ผู้จัดการ — ทำได้ทุกอย่างของพนักงาน และ

ยกเลิกและคืนเงิน

  • ยกเลิกการจองทั้งกลุ่มหรือบางชั่วโมง พร้อมคืนเงิน
  • คืนเงินได้ไม่เกินยอดของชั่วโมงที่ยกเลิก แต้มที่ได้ถูกหักคืน

บันทึกรับเงินสดแทนโอน

  • ลูกค้าจองออนไลน์แต่มาจ่ายสดที่เคาน์เตอร์

ยกเลิกบิลขาย (Void)

  • คืนสต๊อกและหักแต้ม
  • ถ้าลูกค้าเอาแต้มจากบิลนี้ไปแลกคูปองแล้ว คูปองถูกยกเลิกด้วย ถ้าใช้คูปองไปแล้ว ยกเลิกบิลไม่ได้
  • บิลเงินสดในกะที่ปิดแล้ว ยกเลิกไม่ได้

ประวัติกะ

  • ดูกะที่ผ่านมา ยอดที่ควรมี ยอดนับจริง ส่วนต่าง และหมายเหตุ

ผู้ดูแลระบบ — ตั้งค่าร้าน

ราคา

  • กฎราคาตามกีฬา วันธรรมดา/เสาร์-อาทิตย์ และช่วงชั่วโมง (ปกติ / Peak)
  • ส่วนลดตามระดับสมาชิก ราคาครึ่งสนาม
  • เวลาเปิด-ปิด และจองล่วงหน้าได้กี่วัน

ข้อมูลร้าน

  • ชื่อ ที่อยู่ เบอร์ เลขผู้เสียภาษี 13 หลัก จด VAT หรือไม่
  • ใช้บนใบเสร็จ และเป็นชื่อบัญชีผู้รับบนหน้าจ่ายเงิน

สนามและวันปิด

  • เพิ่ม/เปลี่ยนชื่อ/เปิด-ปิดการจองของสนาม
  • ปิดสนามตามวันและเวลา ทั้งสนาม ทั้งกลุ่ม หรือครึ่งสนาม

สินค้าและสต๊อก

  • เพิ่ม/แก้สินค้า ปรับสต๊อก รองเท้าแยกเบอร์
  • นำเข้าสินค้าจากไฟล์ Excel

ผู้ใช้และบทบาท

  • ตั้งระดับสมาชิก ปรับแต้มด้วยมือ (ต้องใส่เหตุผล)
  • ตั้งบทบาทพนักงาน ระงับบัญชี
  • สร้างบทบาทใหม่และเลือกสิทธิ์เองในแท็บบทบาท

รายงานและตรวจสอบ

  • รายงานรายเดือน/รายปี และส่งออกไฟล์
  • บันทึกการแก้ไข (Audit log) ว่าใครทำอะไรเมื่อไร
